Firma Digitale

Configura un solo canale operativo: Aruba Key / Local Signer, oppure un certificato esportabile P12/PFX, oppure PEM. La firma CAdES degli atti e l'accesso PST usano il canale che scegli qui. Rilasciato da: Infocert, Namirial, Aruba, Poste Italiane, Intesa. Guida completa — come ottenerlo e configurarlo

Non servono tutti i formati. Se usi già Aruba Key con Local Signer, il container non deve avere un file P12/PEM: la chiave resta sul token o nel middleware locale del PC. I campi P12/PEM qui sotto servono solo a chi possiede un certificato esportabile e vuole usarlo lato server/container.

Firma in-device — chiave privata mai estratta dal token.

Requisiti: apt install pcscd opensc sul server/Docker host · pip install python-pkcs11 asn1crypto · montare /run/pcscd/pcscd.comm nel container.

{# Guida Brevo — visibile solo quando l'host è smtp-relay.brevo.com #}
Brevo (ex Sendinblue) — istruzioni rapide:
  1. Registrati su brevo.com (piano Free: 300 email/giorno gratuito)
  2. Verifica l'email di conferma — l'SMTP non funziona finché l'account non è attivato
  3. Vai su SMTP & API → SMTP e copia le credenziali
  4. Username: il tuo indirizzo email Brevo
  5. Password: la Master password SMTP (non la password dell'account)
Timeout? L'account potrebbe non essere ancora attivato oppure il dominio mittente non verificato. Accedi a brevo.com e controlla eventuali avvisi nella dashboard.
Gmail: usa una App Password (non la password principale). Abilita l'accesso per app meno sicure o usa OAuth2. Outlook: usa la password dell'account o un App Password se abilitata la 2FA.
