# Componenti UI IUSENTRA

Questa cartella contiene primitive React minime e private, pensate per essere
estratte progressivamente dal frontend solo quando l'import è sicuro.

Regole:

- nessun dato tenant o dato di studio;
- testi di esempio in italiano e privi di dati personali;
- componenti piccoli, accessibili e coerenti con il design system IUSENTRA;
- nessuna dipendenza da route Flask, sessione o storage runtime.
