# 2.473.1 — Pagina Contratti robusta; metodo di lavoro sul codice

- Il deploy della 2.473.0 si è fermato sul controllo Storybook: la pagina Contratti (2.472.0) si rompeva quando il
  servizio rispondeva senza l'elenco delle aree o delle pratiche. Ora una risposta incompleta vale come «Catalogo dei
  contratti non disponibile» e la pagina mostra il messaggio. Bundle React ricompilato.
- `AGENTS.md`: sezione «Metodo di lavoro sul codice» (pensare prima di scrivere, semplicità, modifiche chirurgiche,
  obiettivi verificabili), richiamata in `CLAUDE.md`, su richiesta dell'avvocato.
