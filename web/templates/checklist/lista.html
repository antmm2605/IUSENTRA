Struttura cartelle

Regola cartella e file

[ATTO]_[PARTE]_[GG-MM-AAAA]

La data della cartella usa sempre il formato italiano filesystem-safe gg-mm-aaaa, per esempio Decreto_ingiuntivo_Rossi_19-04-2026.

  • Numerazione file stabile: 01, 02, 03.
  • Nomi file senza caratteri speciali, spazi doppi o simboli non ammessi.
  • Indice e allegati devono combaciare sempre con l'ordine dei file.
  • Gli allegati voluminosi vanno separati in sottocartelle coerenti.
