# Schemi XSD SIGP 2024-08-27

Questa cartella ospita il pacchetto XSD ufficiale SIGP scaricato dal Portale Servizi Telematici.

Fonte ufficiale: https://pst.giustizia.it/PST/it/paginadettaglio.page?contentId=ACC3460

Il registry IUSENTRA punta a `xsd/Professionista.xsd`, coerente con la nota ministeriale del 27/08/2024 che cita `Professionista.xsd` versione 2.0.

Finche' il file non e' presente, il modulo genera l'XML di bozza e restituisce un errore leggibile `SIGP_XSD_MANCANTE`, senza dichiarare il deposito pronto.
