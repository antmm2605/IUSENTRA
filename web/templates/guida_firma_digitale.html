{# ---- 1. Cosa sono i formati ---- #}
I tre formati del certificato — cosa contengono

Il certificato di firma digitale è composto da due elementi: un certificato pubblico (la tua identità digitale) e una chiave privata (con cui firmi i documenti). I provider li rilasciano in formati diversi.

.p12 / .pfx

Bundle unico — contiene certificato + chiave privata + chain CA in un singolo file cifrato con password.

Il più comune — la maggior parte dei provider lo rilascia.
Un solo file da gestire.
.pfx e .p12 sono identici.

.crt / .pem certificato

Solo il certificato pubblico — contiene la tua identità e la chiave pubblica. Non è segreto.

Può includere i certificati CA intermedi (chain).
I certificati caricati devono essere file validi rilasciati dal fornitore di firma.

.key / .pem chiave privata

Solo la chiave privata — il segreto con cui firmi. Non condividere mai questo file.

File riservato — conservalo in modo sicuro.
Può essere in chiaro o protetto da password.

Regola semplice: .p12 = .crt + .key messi insieme in un unico file cifrato. Puoi sempre convertire da un formato all'altro con OpenSSL (vedi sezione Conversione).

Quale formato ho? — Mappa decisionale
Hai una chiavetta USB / smart card / CIE / CNS?
Sì — token fisico

La chiave privata è bloccata dentro il chip — non puoi estrarla (è obbligatorio per legge per i certificati qualificati).

Cosa fare: firma i documenti localmente con il software del provider (ArubaSign, Dike, Namirial Sign) e carica il .p7m già firmato nell'app tramite Fascicoli → Documenti → Firma per deposito.

No — certificato remoto o software

Il provider ti ha fornito un file scaricabile. Continua con il passo successivo.

Che file ti hanno dato?
Un file .p12 o .pfx → usa direttamente come PCT_FIRMA_P12
Un file .crt + un file .key → usa come PEM con PCT_FIRMA_CERT + PCT_FIRMA_KEY
Solo un file .p12 ma vuoi i file separati → converti con OpenSSL (vedi sezione Conversione)
{# ---- 3. Provider italiani ---- #}
Come scaricare il certificato — provider italiani
{# Aruba #}

Certificato remoto (OTP/app)
  1. Accedi su areariservata.aruba.it
  2. Vai in I miei prodotti → Firma Digitale Remota
  3. Clicca Gestisci → Scarica certificato
  4. Scegli il formato P12 e imposta una password
  5. Salva il file .p12 e annotati la password
Token USB ArubaKey

La chiave privata non è estraibile dal token.

Usa ArubaSign (software gratuito Aruba) per firmare i documenti localmente, poi carica il .p7m nell'app.

{# Namirial #}

Firma remota Namirial
  1. Accedi al pannello Namirial con le tue credenziali
  2. Sezione Certificati → Il mio certificato
  3. Clicca Scarica → Formato P12
  4. Se il provider offre PEM: clicca Scarica → CRT + KEY
  5. Salva i file e annota le password
Token USB Namirial

La chiave privata è nel chip del token — non estraibile.

Usa Namirial Sign per firmare localmente.

{# InfoCert / Dike #}

Firma remota
  1. Accedi su infocert.it → Area personale
  2. Firma digitale → Gestione certificati → Esporta
  3. Formato disponibile: P12
  4. Per ottenere PEM separati: converti il P12 con OpenSSL (vedi sezione Conversione)
Chiavetta / CNS

Chiave non estraibile.

Usa Dike 6 per firmare localmente.

{# Poste Italiane #}

  1. Accedi su postecert.poste.it
  2. Firma digitale → Il mio certificato → Scarica
  3. Formato rilasciato: P12
  4. Per PEM separati: converti con OpenSSL
Poste rilascia il P12 solo per i certificati software. Il PosteKey (token USB) non permette l'estrazione della chiave.
{# Intesa Sanpaolo / CA #}

La procedura è analoga per tutti i provider accreditati AgID:

  1. Accedi all'area riservata del provider
  2. Cerca la sezione Firma digitale → Scarica certificato / Esporta
  3. Scegli il formato P12 (universalmente supportato)
  4. Se il provider offre PEM direttamente, scarica .crt + .key

Se non trovi l'opzione di download, contatta il supporto del provider: è possibile che tu abbia solo un token fisico.

{# ---- 4. Conversione ---- #}
Conversione tra formati — comandi OpenSSL

OpenSSL è gratuito e preinstallato su Linux e macOS. Su Windows: usa Git Bash, WSL o scarica OpenSSL for Windows. I comandi sono identici su tutte le piattaforme.

P12 → PEM Hai il P12, vuoi i file separati
1. Estrai il certificato pubblico (.crt):
openssl pkcs12 -in firma.p12 \
  -clcerts -nokeys \
  -out firma.crt
# chiede la password del P12
2a. Estrai la chiave privata in chiaro (più semplice):
openssl pkcs12 -in firma.p12 \
  -nocerts -nodes \
  -out firma.key
# -nodes = no password sulla chiave
2b. Estrai la chiave privata con password (più sicuro):
openssl pkcs12 -in firma.p12 \
  -nocerts \
  -out firma.key
# chiede password P12, poi chiedi nuova password per la chiave
PEM → P12 Hai i file separati, vuoi creare il P12 
openssl pkcs12 -export \
  -in firma.crt \
  -inkey firma.key \
  -out firma.p12 \
  -name "Firma avvocato"
# ti chiede la password per proteggere il P12
Verifica Controlla il contenuto di un certificato 
# Verifica file .crt
openssl x509 -in firma.crt -noout -subject -dates

# Verifica file .p12
openssl pkcs12 -in firma.p12 -noout -info
Nota sulla scadenza: i certificati di firma qualificata scadono ogni 3 anni. Il comando openssl x509 -in firma.crt -noout -dates mostra le date di validità. Rinnova prima della scadenza contattando il tuo provider.
{# ---- 5. Token / Smart card ---- #}
Token USB / Smart card / CNS / CIE — caso speciale
La chiave privata nei token fisici non è mai estraibile. È un requisito di legge (CAD e Regolamento eIDAS) per i certificati di firma qualificata: garantisce che solo il titolare possa firmare, fisicamente in possesso del dispositivo.
Workflow consigliato con token
  1. Scarica il documento da firmare dall'app (Fascicoli → Documenti → Scarica)
  2. Apri il software del provider sul tuo PC con il token inserito
  3. Firma il documento → ottieni il file firmato da caricare nel fascicolo
  4. Torna nell'app → Fascicoli → Documenti → Firma per deposito
  5. Carica il file già firmato
  6. Il documento viene marcato come "firmato digitalmente" e pronto per il deposito

{# ---- 6. Configurazione Docker ---- #}
Configurazione nel server / Docker

Il file del certificato deve essere accessibile dal server dove gira l'applicativo. Con Docker, la modalità più semplice è montarlo nel volume /data/config/.

Opzione AFormato P12 — file .env
# Copia il file nel volume dati
cp firma.p12 ./data/config/firma.p12

# Nel file .env
PCT_FIRMA_P12=/data/config/firma.p12
PCT_FIRMA_PASSWORD=la_tua_password
PCT_CF_AVVOCATO=RSSMRA80A01H501Z
Opzione AIn docker-compose.yml
volumes:
  - ./data:/data
  # Il file è già in ./data/config/firma.p12
  # Non serve un mount aggiuntivo
Opzione BFormato PEM — file .env
# Copia i file nel volume dati
cp firma.crt ./data/config/firma.crt
cp firma.key ./data/config/firma.key

# Nel file .env
PCT_FIRMA_CERT=/data/config/firma.crt
PCT_FIRMA_KEY=/data/config/firma.key
# Solo se la chiave è protetta da password:
PCT_FIRMA_KEY_PASSWORD=password_chiave
PCT_CF_AVVOCATO=RSSMRA80A01H501Z
Opzione BPermessi file
# La chiave privata deve essere leggibile solo dall'app
chmod 600 ./data/config/firma.key
chmod 644 ./data/config/firma.crt
In alternativa alle variabili d'ambiente, puoi configurare i percorsi direttamente dall'interfaccia: Impostazioni → Firma Digitale . I valori vengono salvati cifrati nel file /data/config/studio.json.
