# Specifiche Ministeriali

Questa cartella raccoglie gli asset ufficiali di supporto tenuti sotto versione:

- PDF ministeriali
- pacchetti WSDL e XSD
- DTD e certificati di riferimento
- materiale tecnico PST, PDP, PAT e canali correlati

Regola di repo: questi file non devono stare in root. Se vengono aggiunti o aggiornati, vanno mantenuti qui.

Regola notifiche/telematico: quando una funzione dipende da una normativa,
direttiva, XSD, DTD, schema XML, tracciato PEC/EML o specifica ministeriale, la
fonte deve essere salvata qui o in un documento tecnico collegato prima di
usarla nel codice. Se la fonte non è ancora presente, va ricercata su fonte
ufficiale, registrando data di consultazione, ambito applicativo e limite della
regola adottata.

## Fonti notifiche e deposito prova salvate

- `notifiche_legali_directives.md`: registro locale delle regole runtime per
  PEC ufficio, relata, allegati, firma, invio PEC, RAC/RdAC, area web PST e
  controlli orari.
- `Specifiche_Tecniche_DGSIA_DM44_2011_2024_08_07.pdf` e rettifiche 2024:
  fonte corrente per comunicazioni ufficio, avviso di disponibilità, rilascio
  copie, notificazioni degli avvocati e attestazioni.
- `xsd/2026-05-12-sici/`: XSD SICI PST pubblicati il 12 maggio 2026 e relativa
  nota modifiche, mantenuti offline per controlli deposito collegati alla prova
  della notifica.
