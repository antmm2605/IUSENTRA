# 2.470.7 — Le discordanze false già registrate non si mostrano più

- Il riquadro delle discordanze mostrava ancora le 11 discordanze false individuate il 01/11/2026 (ente al posto
  del cliente, secondo nome, codici fiscali letti male): le regole nuove le chiudono alla rilettura del fascicolo,
  che era ferma. Ora l'elenco applica le regole correnti anche alle discordanze già registrate e mostra solo quelle
  vere; la chiusura definitiva avviene con la rilettura (pianificazione «Recupero completo delle letture»).
