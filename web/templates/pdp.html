Come funziona adesso il modulo PDP
Ricerca guidata
La ricerca libera con molti campi e' stata rimossa: il gestionale usa il percorso guidato per cercare, verificare e importare il fascicolo corretto senza creare doppioni.
Importazione intelligente
Se la pratica esiste gia', HACS la integra. Se manca, la crea. Nel penale aggancia anche il workflow PDP per accesso atti, PEC, password e import fascicolo. Dopo il download dal portale, l'import dei file reali avviene nella Fase 7 dell'acquisizione guidata oppure dal workspace PDP. Il pulsante Importa file gia scaricati apre direttamente il wizard con questo focus.
Credenziali
Il PDP usa le stesse credenziali CNS del PCT civile. Configurale in Impostazioni -> Firma Digitale.
