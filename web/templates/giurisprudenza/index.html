Ricerca legale

Principi di progetto

Classificazione doppia: area / branca / sottobranca e, in parallelo, giurisdizione / grado / rito / organo.
Fonte separata: Cassazione, merito civile, Corte costituzionale, amministrativo, tributario, UE e CEDU non vengono mischiati in un contenitore piatto.
Recupero prudente: sincronizzazione leggera solo sulle fonti aperte; handoff assistito per PST, portali autenticati e motori non esposti come API pubbliche.

Import assistito da materiale cliente

Usa questa area per Simpliciter o altre fonti non sincronizzabili direttamente: IUSENTRA importa solo URL, testo, PDF o HTML che hai già ottenuto legittimamente, poi crea o aggiorna automaticamente le schede sentenza.
Nessuno scraping del portale
Se il materiale contiene più sentenze, il sistema tenta una separazione automatica per ECLI, numero provvedimento e blocchi redazionali. I duplicati vengono aggiornati invece di creare doppioni.
