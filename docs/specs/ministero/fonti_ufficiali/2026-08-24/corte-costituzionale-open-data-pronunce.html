I dataset

  
I dataset attualmente pubblicati riguardano:

- l'archivio delle pronunce (circa 18.000 testi delle pronunce della Corte costituzionale dal 1956 ad oggi),

- l'archivio delle massime delle pronunce,

- l'anagrafica dei Giudici costituzionali: l'elenco di tutti i Giudici costituzionali con le date di giuramento, di cessazione e una breve nota biografica,

- le norme pendenti nei giudizi dinanzi alla Corte costituzionale: per ogni tipologia di giudizio il file xml contiene gli estremi delle norme o degli atti impugnati ed i parametri costituzionali evocati.
