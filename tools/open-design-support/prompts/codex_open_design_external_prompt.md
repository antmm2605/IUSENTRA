# Prompt per usare Open Design come laboratorio esterno

Obiettivo:
generare un prototipo grafico per IUSENTRA senza modificare direttamente il codice prodotto.

Contesto:
IUSENTRA e' un gestionale professionale per studi legali italiani.
Usa il design system `IUSENTRA_DESIGN.md`.
Usa tono sobrio, istituzionale, operativo.

Regole:
- non inventare moduli;
- non usare lorem ipsum;
- non usare inglese nella UI;
- non creare estetica startup generica;
- gestire stati vuoti/loading/errore;
- produrre HTML o descrizione strutturata;
- prima prototipo, poi integrazione.

Output richiesto:
- direzione grafica;
- struttura pagina;
- componenti;
- microcopy;
- note responsive;
- rischi di integrazione;
- criteri di accettazione.
